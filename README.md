# Tech Sphere Academy: Data Science (ts-data-science)

This repository contains my comprehensive coursework, project files, and advanced analytics models for the Tech Sphere Academy Data Science curriculum. My primary objective throughout this program is to master data science methodologies, advanced feature engineering, and the practical deployment of predictive machine learning models. By bridging local environment architectures with cloud runtimes, I aim to build a robust, reproducible portfolio of data pipelines that transform raw data into highly accurate, actionable business insights.

## 📁 Repository Structure

*   **`data/`** - Raw and processed datasets used throughout the course.
*   **`notebooks/`** - Jupyter notebooks for exploratory data analysis (EDA) and model prototyping.
*   **`src/`** - Modularized Python source scripts for reusable pipeline functions.
*   **`models/`** - Serialized model objects and weights (`joblib` binaries) ready for scoring and deployment.
